# Learned-of-Html-CSS-and-Js
learning of html, Css and Js
🌐 Learned-of-HTML-CSS-and-JS

This repository documents my learning journey in HTML, CSS, and JavaScript. It contains structured practice files, mini projects, experiments, and concept-based implementations that helped me build a strong foundation in frontend web development.

The goal of this repository is not just to write code, but to understand how the web works from scratch — how structure, styling, and interactivity come together to build real-world websites.

📚 What I Learned
🔹 HTML (HyperText Markup Language)

Structure of a webpage

Semantic elements (header, section, article, footer, etc.)

Forms and input types

Tables and lists

Media elements (images, audio, video)

SEO basics and accessibility fundamentals

🔹 CSS (Cascading Style Sheets)

Selectors and specificity

Box model (margin, padding, border)

Flexbox and Grid

Positioning (relative, absolute, fixed, sticky)

Responsive design using media queries

Animations and transitions

Modern layout practices

🔹 JavaScript

Variables (var, let, const)

Data types and operators

Functions and scope

Arrays and objects

DOM manipulation

Event handling

Basic form validation

ES6 concepts (arrow functions, template literals, etc.)

💻 Projects & Practice Work

This repository includes:

Static webpage designs

Responsive layouts

Interactive UI components

Form validation projects

Small JavaScript-based mini apps (like calculator, to-do list, etc.)

Each project focuses on applying core concepts practically rather than only theoretical understanding.

🎯 Purpose of This Repository

To build a strong frontend foundation

To practice writing clean and organized code

To understand how HTML, CSS, and JavaScript work together

To track progress and improvement over time

To prepare for advanced topics like React, backend development, and full-stack projects
